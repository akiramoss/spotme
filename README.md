# SpotMe

App de bookmarks geolocalizados personales. Guarda lugares que te importan (cafeterías, spots para fotos, sitios para estudiar) con descripción, categoría y ubicación, en tu propio mapa personal.

Proyecto en desarrollo — Beta 1: bookmark personal de spots, sin funcionalidad social todavía.

## Stack

- Java 25
- Spring Boot 4.1.1
- Maven

## Requisitos

- JDK 25
- Maven 3.9+

## Cómo correrlo

```bash
mvn spring-boot:run
```

La app arranca en `http://localhost:8080`.
